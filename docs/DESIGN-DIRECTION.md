# KORYX design direction

User preference, established 13 October 2026:

- Do not use generic presentation cards, floating cards, nested browser mockups, or miniature sample websites to explain KORYX's work or process.
- Build original interactive compositions directly in code. Use continuous spatial graphics, living typography, meaningful transformations, and open editorial layouts.
- Keep the established neutral KORYX palette, typography, and light/dark themes. Avoid monospaced display styling and unnecessary coloured backgrounds.
- Interactions must work with a mouse and touch, respect reduced motion, pause when offscreen, and preserve ordinary page scrolling.
- Explain real project terms accurately. Do not invent customer results, performance figures, deadlines, or completed client projects.
- Change only the page or section requested. This preference does not authorize a site-wide redesign.

The freight cutaway has an additional specific rule: its thin horizontal reveal line is moved manually by the pointer or by dragging the line on touch devices. Scrolling never moves the scanner. Only the revealed interior is blue.
